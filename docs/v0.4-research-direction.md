# v0.4 research direction: one dyadic social geometry experiment

**Status:** proposed, not implemented. No CalMS21 pose archive has been
downloaded or analyzed for Umwelt. Version 0.4 begins only after source,
license, identity, and pose-quality gates are documented.

## First question

Can a minimal, explicit dependence on another animal's current position help a
generative pair model reproduce the distribution and short-term dynamics of
inter-animal distance? This is a question about measured spatial interaction,
not inference of social intention, motivation, hierarchy, or welfare.

The first world contains two distinct mouse identities and their observed
positions on a common image-space frame grid. It does not add food, reward,
latent psychology, general physics, or a multi-species interaction engine.

## Candidate source

[CalMS21](https://data.caltech.edu/records/s0vdx-0k302)
(`10.22002/D1.1991`) provides top-view tracked poses of interacting resident
and intruder mice. Its [source readme](https://data.caltech.edu/records/s0vdx-0k302/preview/readme.md?include_deleted=0)
specifies seven keypoints per mouse, confidence scores, pixel coordinates, and
Task 1 train/test sets separated by animal identity. The Task 1 pose/archive
download is listed as 457.4 MB; the much larger video archives are not needed
for an initial pose-only feasibility check. The
[dataset paper](https://arxiv.org/abs/2104.02710) describes a
CC-BY-NC-SA data license. Confirm the exact applicable terms before use;
keep source data outside the Apache-licensed code repository and retain its
license and attribution in provenance. The source was designed for behavior
classification, so Umwelt's generative question requires its own protocol.

CalMS21 is a candidate, not an adopted dataset. Download only the Task 1 pose
archive for the first source audit. Verify its published MD5, actual contents,
animal-pair identities, frame grid, missing coordinates, confidence values,
and whether any sequence or animal crosses the provided split. If these facts
cannot support a leakage-safe generative experiment, select another source
before inspecting model outcomes.

## Observation contract to freeze before modeling

- Preserve resident and intruder identities, recording identity, source type,
  frame index, image axes, pixel units, and every source confidence value.
- Start with the **neck** keypoint as each animal's representative position;
  it exists in the declared seven-keypoint schema. Do not relabel it as a
  body centre. Preserve unavailable or rejected positions as explicit gaps.
- Derive pair distance only when both neck positions are accepted in the same
  frame. Derive signed distance change only across adjacent valid pair frames.
- Keep expert action annotations separate from geometric observations. They
  may provide context in a later analysis but are not ground truth for a
  modeled social mechanism.
- Do not invent physical distance, arena dimensions, or a score threshold.
  Source-quality rules and any threshold need a documented basis before the
  held-out test animals are inspected.

## Narrow model ladder

**S0: independent pair baseline.** Fit a separate simple movement process to
each role using only development animals. Generate two trajectories on one
frame grid with independent random streams, then measure pair geometry. This
tests how much apparent interaction can arise from individual movement and a
shared recording setting alone.

**S1: distance-conditioned pair model.** Keep the same individual movement
components and add one explicit dependence of the resident's next movement
direction on the current resident-to-intruder vector. The dependency may vary
with measured pair distance, but its parameterization and eligible observations
must be fixed before testing. It does not claim a biological drive to approach
or avoid the intruder.

Both models must obey the same frame grid, observation mask, image-space
constraints supported by the source, and seed contract. Synthetic outputs
retain model and source identities. A change to an animal's trajectory caused
by S1 is a model effect, not a causal intervention on a real pair.

## Development and evaluation boundary

Use only the provided Task 1 training animals for schema audit, fitting, and
design choices. Reserve the source test animals untouched until the exact
preference rule, metrics, masks, number of replicates, and exclusions are frozen
in code and documentation. The unit for summaries is an independent recorded
pair/session as supported by source identities; frames and synthetic replicates
do not count as independent biological pairs. Check repeated animals or pairs
within the train and test collections before finalizing that unit.

The planned primary comparisons are the pair-distance distribution in pixels
and the distribution of adjacent signed pair-distance changes, each reported
with valid-frame or transition exposure. Secondary descriptions may include
near/far occupancy and contiguous distance-decrease runs, provided their
thresholds and gap handling are declared before testing. Report per-pair
results and aggregate across pairs; preserve null, missing, and negative
results. Decide the S1 preference rule using only development data, then
execute it once on held-out test identities.

## Implementation sequence

1. Audit source rights, checksums, schema, identities, and split without using
   test outcomes for design.
2. Implement a small two-animal observation and gap-aware pair-measurement
   contract, with provenance tests.
3. Freeze S0, S1, paired seeds, metrics, preference rule, and reproducibility
   artifacts on the development split.
4. Run the held-out evaluation once and retain the result even if S1 fails.

The completed v0.3 negative result remains separate. Its M1 model is not
silently promoted into S0 or S1, and CalMS21 cannot repair the earlier v0.3
decision.
