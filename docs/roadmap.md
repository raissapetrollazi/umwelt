# Roadmap

This roadmap is deliberately conservative. Stages after Stage 0 are planned directions and do not represent current capabilities.

## Stage 0 - Foundation

Repository identity, scientific principles, architectural direction, licensing, Python project metadata, and initial documentation.

## Stage 1 - First Recorded Dataset

Planned. Define the first narrow research question and select one appropriate open dataset.

## Stage 2 - Replay

Planned. Support reproducible inspection of recorded animal observations from the selected dataset.

## Stage 3 - First Explicit Behavioral Model

Planned. Build a narrow generative model tied to the first research question, with documented assumptions and recorded configuration.

## Stage 4 - Simulation and Comparison

Planned. Generate synthetic behavior and quantitatively compare it against recorded observations.

## Stage 5 - Controlled Computational Interventions

Planned. Introduce counterfactual interventions only after the basic model has been validated enough to justify them.
