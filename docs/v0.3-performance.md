# v0.3 execution performance audit

The canonical v0.3 experiment remains the frozen 16-replicate run in
`runs/v0.3-behavioral-world/`. Performance work must preserve its scientific
definitions, random streams, fitted parameters, and measured outcomes.
Its provenance records package version `0.2.0` at Git revision `9a6dfb7`
because the run preceded the `0.3.0` package-version update. Historical
provenance is retained as generated, not rewritten to match the later tag.

## Measurement

On 2026-09-26, one complete 1-replicate run (34 generated series) used the
canonical Roche inputs and seed on a 12th Gen Intel Core i7-1255U with Python
3.14.4. A `cProfile` run identified source CSV parsing, world-zone measurement,
and trajectory generation as the largest cumulative costs. Profiler overhead
was excluded from the wall-time comparison.

| Implementation | Wall time | Generated series |
| --- | ---: | ---: |
| Before zone reuse | 115.035 s | 34 |
| After zone reuse | 110.429 s | 34 |

The change reuses each position's existing zone assignment when classifying
the following valid transition. On this one run it saved 4.606 s (4.0%).
Runtime varies with machine load; this is a measured sample, not a performance
guarantee for every configuration.

The two runs produced byte-identical `world.json`, `models.json`,
`interventions.json`, `protocol.json`, `seeds.json`,
`replicate-metrics.jsonl`, `model-comparison.json`,
`intervention-comparison.json`, and `report.md`. Configuration, provenance,
and manifest bytes differ because run paths and tracked Git state differ.
All unit tests, lint, formatting, and spatial/world typing checks passed after
the optimization. The 16-replicate canonical result was not replaced or
reinterpreted.
