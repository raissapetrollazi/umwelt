# Data and Ethics

Initial Umwelt development should prioritize public or open datasets that were previously collected. The project does not authorize, prescribe, or require new animal experimentation.

## Dataset Use

Dataset licenses must be respected. Original provenance, authorship, versioning, and access conditions should be preserved in future dataset integrations and derived artifacts.

Original experimental conditions matter. When recorded data is used, future documentation should preserve relevant context such as recording conditions, preprocessing steps, annotations, exclusions, and known limitations.

## Traceability

Derived outputs should remain traceable to their source data and transformation steps. Recorded animal data must not silently become synthetic training or evaluation data without documentation.

Synthetic results must be labeled as synthetic. Generated behavior should not be presented as direct evidence about real animals.

## Future Animal Data

Any future use involving newly collected animal data would require appropriate institutional, ethical, and legal processes outside the scope of this software.

Umwelt documentation and software should avoid implying that running the software is sufficient authorization for animal experimentation.
