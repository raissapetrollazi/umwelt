# Scope

Umwelt is intended to study animal behavior by connecting recorded observations with explicit computational models. The project is planned as a headless-first scientific system for replaying recorded data, constructing behavioral models, generating synthetic behavior, running controlled simulations, and quantitatively comparing generated behavior with recorded behavior.

Umwelt is not yet a working simulator. The current repository defines the project foundation: scope, scientific principles, architectural direction, documentation, licensing, and a Python package skeleton.

## Observation, Modeling, and Simulation

Umwelt treats recorded observations, annotations, derived measurements, inferred variables, model parameters, synthetic trajectories, synthetic behavioral states, and synthetic internal model variables as distinct information categories.

Those categories must remain distinguishable in documentation, future data artifacts, experiment configuration, evaluation, and reporting.

Replay and simulation are also distinct. Replay represents fixed recorded history. Simulation represents behavior generated by an explicit computational model and may support interventions and counterfactual branches.

## Headless-First Direction

Umwelt should be usable without graphical rendering. A physically or spatially explicit environment may contain position, orientation, trajectories, geometry, objects, zones, resources, environmental state, and other animals while remaining completely headless.

Rendering and simulation are separate concerns. Future graphical interfaces may exist, but they must not become a requirement for scientific simulation.

## First Research Milestone

The first planned research milestone is **v0.1 — Sleep / Activity Mouse**.

Its core question is:

> Can a compact, explicit generative model reproduce key temporal properties of recorded mouse sleep/activity dynamics?

The milestone is intended to establish the first complete recorded-to-synthetic scientific loop before adding spatial, social, environmental, or neural complexity. No dataset is currently described here as integrated, and the planned capabilities are not current capabilities.

## Out of Scope for the Foundation Stage

The following are postponed while the repository remains in its foundation stage; they are not permanent project non-goals:

- simulator implementation;
- behavioral models;
- dataset integration;
- a functional CLI;
- machine learning;
- graphical interfaces;
- real-time acquisition.

## Project Non-Goals

Permanent boundaries include:

- reconstructing animal consciousness;
- claiming or reconstructing subjective experience;
- inferring true intention solely from observed behavior;
- equating synthetic internal variables with real biological mental states;
- simulating a complete biological brain as a project claim;
- veterinary or medical diagnosis;
- replacing biological experiments;
- becoming a general-purpose artificial-life platform.

These are boundaries on claims and purpose, not reasons to make the computational research program small.
