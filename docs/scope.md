# Scope

Umwelt studies animal behavior by connecting recorded observations with
explicit computational models. It is a headless-first scientific system for
replaying fixed recorded histories, generating synthetic behavior under stated
assumptions, and quantitatively comparing those categories.

## Current scope

Version 0.1 implements one narrow temporal laboratory: **Sleep / Activity
Mouse**. It asks which minimal explicit temporal mechanisms reproduce selected
properties of recorded mouse sleep/activity dynamics.

The current implementation provides:

- a pinned and checksum-verified adapter for the COMPASS Zenodo deposit;
- paired loading of weekly PIR activity and behaviorally defined sleep labels;
- explicit `recorded` and `synthetic` source categories;
- recorded-data replay through a headless CLI;
- a four-model factorial ladder separating phase and elapsed-bout-duration
  conditioning;
- one shared phase- and state-conditioned activity-emission model;
- seeded generation of synthetic state and activity sequences;
- deterministic replicated development comparison of occupancy, activity,
  transitions, empirical bout distributions, daily phase, and sleep-state
  autocorrelation;
- aggregate and individual-subject predictive simulation summaries;
- resolved configuration, provenance, seed, report, and checksum artifacts.

This scope establishes a complete computational loop. It does not establish
that the baseline is biologically sufficient, and it does not turn Umwelt into
a general simulator.

## Observation, modeling, and simulation

Umwelt treats recorded observations, annotations, derived measurements,
inferred variables, model parameters, synthetic trajectories, synthetic
behavioral states, and synthetic internal variables as different information
categories.

Replay presents fixed recorded history. It can select and stream observations,
but cannot intervene in what occurred. Simulation creates new history from an
explicit model. A shared timestamp grid does not make synthetic observations
recorded observations; every emitted row retains its source category.

The COMPASS weekly sleep column is a recorded derived label based on extended
PIR immobility. It is neither a direct physiological measurement nor a model
state generated by Umwelt. That distinction is preserved in documentation and
provenance.

## Headless-first direction

All current functionality runs without graphics. This is a permanent design
constraint, not a temporary omission. Future environments may contain spatial,
physical, social, or contextual state while remaining completely headless.
Rendering, if introduced, will remain separate from scientific simulation.

## Why the first milestone is narrow

A two-state temporal problem is small enough to inspect end to end. The source
files, transformations, split, model parameters, random seeds, generated rows,
metrics, and discrepancies can all be examined directly. This allows Umwelt to
test its scientific infrastructure before adding space, interaction, neural
signals, model selection, or intervention.

The first baseline fails on important bout-duration and longer-lag temporal
structure. The expanded model ladder tests phase and duration memory separately
without hiding those failures or changing activity emissions at the same time.

## Current non-goals

Version 0.1 does not provide:

- spatial trajectories, pose, arenas, objects, or environmental dynamics;
- controlled interventions or counterfactual branching;
- social interaction models;
- raw EEG processing or physiological-data integration;
- model fitting through machine learning or deep learning;
- real-time acquisition or monitoring;
- graphical rendering;
- a general plugin or dataset framework;
- claims of causal or biological mechanism recovery.

## Permanent boundaries

Umwelt does not reconstruct consciousness or subjective experience, infer true
intention solely from observed behavior, equate synthetic variables with real
mental states, simulate a complete biological brain as a scientific claim,
provide veterinary or medical diagnosis, replace biological experiments, or
serve as a general-purpose artificial-life platform.
