# Scope

Umwelt is intended to study animal behavior by connecting recorded observations with explicit computational models. The project is planned as a headless-first, CLI-first scientific software system for replaying recorded data, constructing narrow behavioral models, running simulations, and comparing generated behavior with recorded behavior.

Umwelt is not yet a working simulator. The current repository defines the initial scope, scientific principles, documentation, licensing, and Python package skeleton.

## Observation, Modeling, and Simulation

Umwelt treats behavioral observation, interpretation, and simulation as separate concepts.

Recorded observations are measurements or annotations derived from real animals. Interpretations are claims derived from those observations. Model states are internal variables of computational models. Synthetic behavior is behavior generated by those models.

These categories must remain distinguishable in documentation, data artifacts, experiment configuration, and future APIs.

## Headless-First Direction

Umwelt is planned to be usable without a graphical 3D environment. A graphical interface may exist in the future, but it should not define the early architecture.

The intended foundation is headless and CLI-first so experiments can be scripted, reproduced, inspected, and run in automated environments.

## Explicit Environments

Where spatial or contextual structure matters, Umwelt should represent environmental state explicitly rather than treating behavior as isolated time series. Environments may eventually describe arenas, objects, boundaries, experimental conditions, or other contextual variables needed to interpret movement and behavior.

This is a planned direction, not a current implementation.

## First Milestone

The first scientific milestone has not been selected.

It should be deliberately narrow and defined only after choosing a specific research question and an appropriate open dataset. The first milestone will likely involve one species, one recorded dataset, a small number of behavioral variables or states, one simple environment or recorded context, and one validation target.

## Current Non-Goals

- Implementing a simulator.
- Implementing behavioral models.
- Integrating datasets.
- Adding machine learning.
- Adding a functional command-line interface.
- Building a graphical interface.
- Supporting real-time monitoring.
- Acting as a veterinary or medical tool.
- Replacing biological experiments.
- Inferring animal consciousness, subjective experience, or true intention from behavior.
