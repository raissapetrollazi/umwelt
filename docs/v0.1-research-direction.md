# v0.1 Research Direction — Sleep / Activity Mouse

This is a research-planning document, not an implementation specification. It does not claim that a dataset, replay system, behavioral model, simulator, or evaluation workflow has already been implemented.

## Core Question

> Can a compact, explicit generative model reproduce key temporal properties of recorded mouse sleep/activity dynamics?

## Why Begin Here

A temporal sleep/activity system provides a deliberately constrained first organism. It lets Umwelt establish its complete scientific loop before adding space, social interaction, environmental complexity, or neural complexity.

The intended loop is:

```text
recorded observations
    -> explicit representation
    -> explicit generative model
    -> synthetic behavior
    -> quantitative comparison
```

The purpose is not merely to classify recorded states. The model must generate new behavioral sequences that can be compared with recorded dynamics.

## Dataset Requirements

The initial dataset should ideally provide:

- mouse activity measurements;
- sleep/wake or related behavioral-state information;
- sufficient temporal continuity;
- documented experimental conditions;
- clear provenance;
- research-accessible or open licensing;
- manageable computational size.

A dataset in which activity-based measurements can be compared against EEG-derived sleep scoring would be especially useful.

COMPASS is a current leading candidate for consideration, but this document does not describe it as integrated or permanently selected. Final selection should depend on the scientific question, access and licensing, provenance, experimental context, temporal structure, and practical suitability.

## Initial Model Philosophy

The first behavioral model should preferably be:

- small;
- interpretable;
- generative;
- explicitly stochastic when appropriate;
- reproducible from seeds;
- capable of generating new sequences.

Deep learning should not be the default for v0.1. This is not an ideological prohibition: more complex models may be introduced later if justified by a scientific question or by empirical failure of simpler models.

## Candidate Evaluation Dimensions

Possible comparisons include:

- state occupancy;
- bout-duration distributions;
- transition structure or transition frequencies;
- activity distributions or profiles;
- temporal rhythms;
- temporal dependence;
- autocorrelation or related statistics.

These are candidate evaluation dimensions, not implemented features. The final evaluation set should be justified by the selected dataset and model.

## Scientific Success Criteria

v0.1 should only be considered scientifically complete when Umwelt can:

1. ingest the selected dataset while preserving provenance;
2. replay recorded observations;
3. configure or fit at least one explicit generative model;
4. generate synthetic behavioral sequences;
5. reproduce runs from configuration and seeds;
6. quantitatively compare recorded and synthetic behavior;
7. report where the model fails to reproduce recorded dynamics.

Negative results are valid results. A model that fails in an informative and reproducible way may still produce a scientifically useful Umwelt experiment.

## Scientific Boundaries

v0.1 does not claim that sleep/activity states reconstruct subjective experience, intention, or consciousness. A synthetic state is a computational state of the model, and recorded state labels are measurements or annotations with their own provenance and limitations.

The milestone should remain narrow enough that every scientific claim can be tied to recorded evidence, explicit assumptions, reproducible computation, and quantitative comparison.
