# v0.4 CalMS21 Task 1 source audit

**Decision:** usable for Umwelt's non-commercial v0.4 research experiment, with
the identity and tracking limits below. This is a source-quality decision, not
evidence that either social model is adequate. The Task 1 test trajectories have
not been used to design the experiment or calculate model outcomes.

## Source and integrity

The source is the [CalMS21 deposit](https://data.caltech.edu/records/s0vdx-0k302),
DOI `10.22002/D1.1991`, Task 1 pose archive. Its published MD5 and the local
verified MD5 both equal `8a02654fddae28614ee24a6a082261b8`. The archive is
457,357,950 bytes; the locally calculated SHA-256 is
`f1cd2f46771cc3834020d187604da53e5ff330121f5a816146f14192fb0bf427`.
The dataset [paper's license section](https://arxiv.org/html/2104.02710v4)
states CC-BY-NC-SA and links to version 2.0 terms. The archive stays under
ignored `data/raw/` and is not part of Umwelt's Apache-licensed source code.

The archive contains Task 1 train and test pose JSON, matching derived-feature
JSON files, and a directory entry. The audit uses only the pose JSON. The
provided split has 70 training sequences and 19 test sequences. The names
expose `mouse001`–`mouse070` in train and `mouse071`–`mouse089` in test: no
exposed animal key overlaps. Source documentation says the split is by animal
identity. It does not expose a cross-recording identifier for each intruder,
so we cannot independently verify every animal's identity separation. The
independent unit for Umwelt's report is a recording/pair sequence, not a frame.

## Training pose quality

The 70 train sequences contain 507,738 frames, from 96 to 21,364 frames per
sequence. All 7,108,332 keypoint confidence values and all coordinates are
present. Every resident and intruder neck point lies inside the declared
1024 × 570 image. This provides 507,738 valid pair positions and 507,668
adjacent pair transitions with the present all-finite rule.

Confidence and large-motion diagnostics still matter:

| Training diagnostic | Count |
| --- | ---: |
| All-keypoint confidence below 0.1 | 20,127 / 7,108,332 |
| Neck confidence below 0.1 | 92 / 1,015,476 |
| Neck confidence below 0.5 | 13,500 / 1,015,476 |
| Adjacent neck displacement above 50 px | 3,979 / 1,015,336 |
| Adjacent neck displacement above 100 px | 1,644 / 1,015,336 |
| Adjacent neck displacement above 200 px | 1,233 / 1,015,336 |
| Above 100 px with current neck score below 0.5 | 809 / 1,015,336 |

The largest adjacent neck displacement is about 908.4 px. A large displacement
may be a tracking error, a role swap, or a real event; poses alone do not settle
which. The thresholds in this table describe quality and do not filter the
recorded evaluation. Retain all finite source positions and confidence values
for pair-distance measurements. Any robust fitting rule must be declared before
model results are inspected, and exclusions from fitting must be reported.

## Reproduce

With the archive in `data/raw/calms21/` and the optional `calms21` dependency
installed, run:

```console
umwelt social-audit \
  --archive data/raw/calms21/task1_classic_classification.zip \
  --output runs/v0.4-source-audit/report.json
```

The command rejects a mismatched published MD5, records the archive SHA-256,
and reports each training sequence. It parses test JSON only to collect the
sequence names; it does not retain or summarize test poses or annotations.
The output path must be new so an earlier audit is not overwritten.
